## CN2 GIA 到底是什么线路

一句话：它是电信 CN2 网络（AS4809）里的最高档产品，去程回程全程走电信精品网，163 骨干网晚高峰那些拥堵和丢包，理论上都跟它无关。

电信的回国线路大致分四档，价格从低到高：

- **AS4134（163 骨干网）**：绝大多数云厂商的默认线路，容量大、便宜，晚高峰拥堵严重；
- **AS4809 CN2 GT**：本意是缓解 163 的拥堵，但 2019 年之后不少地区的高峰表现已经和 163 差不多；
- **AS4809 CN2 GIA**：精品网最高档。搬瓦工自己的文档标注过，CN2 GIA 的 IP 转接成本最高可到 $120/Mbps——照这个价，一条 1Gbps 的 GIA 专线月成本理论上要 10 万美元级别；
- **AS23764 CTGNet**：电信国际的新网络，定位接近 GIA。

这也是为什么市面上真正卖 CN2 GIA 的商家不多：要么把端口限到 5–10Mbps，要么价格直接翻几倍。搬瓦工（BandwagonHost）是 IT7 Networks 旗下的老牌 VPS 品牌，2004 年成立，自己持有机房和 IP 资源，能把这块成本压下来一些。

光有电信 GIA 还不够。搬瓦工洛杉矶 DC9 机房对中国大陆的回程做了三网聚合：电信走 CN2 GIA（AS4809），移动走 CMIN2（AS58807），联通走精品网（AS10099）。家里谁用哪家运营商，就走对应的高端线路——这一点对多人共用的场景很实际，毕竟你没法给全家人统一运营商。

代价也要说清楚：CN2 GIA 的带宽容量有限，而且基本不抗 DDoS，被大流量攻击时商家通常直接空路由保线路。拿它做容易被打的业务，属于用错场合。

**CN2 GIA 和 CN2 GT 差在哪？** GT 是 Global Transit，通常只有去程走 CN2，回程容易落回 163 骨干；GIA 是 Global Internet Access，双向全程精品网。晚高峰看视频、开会，两者的差距会非常直观。

**1GB 内存够用吗？** 跑轻量系统、代理和小型博客够；想同时跑数据库、面板和一堆容器会经常撞内存墙，这种情况直接看 40G 或更高配置。
